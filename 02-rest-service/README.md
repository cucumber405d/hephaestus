# 02-rest-service

Сервис **Catalog** (изделия и категории мастерской) — эталонный production-grade REST-сервис: контракт
`catalog-api.yaml` (OpenAPI 3.1) → сгенерированные интерфейсы, гексагональная архитектура, JPA + PostgreSQL +
Flyway, тесты на настоящей БД через Testcontainers.

Документация: [docs/start.md](docs/start.md), [docs/architecture.md](docs/architecture.md),
[docs/learning-notes.md](docs/learning-notes.md). Спека и план — [docs/superpowers/](docs/superpowers/).
