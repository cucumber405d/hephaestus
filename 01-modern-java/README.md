# 01-modern-java

Язык и API Java 9–27 на примерах «Мастерской Гефеста». Пакет на релиз (`java09` … `java27`), фича лежит
в версии, где стала финальной. Каждая фича — класс + тест; ключевые утверждения доказаны тестами.

- `features/` — Java 25, все финальные фичи 9–25
- `next/` — Java 27 + `--enable-preview`: финальное из 26 и превью 27

Документация: [docs/start.md](docs/start.md), [docs/architecture.md](docs/architecture.md),
[docs/learning-notes.md](docs/learning-notes.md). Спека и план — [docs/superpowers/](docs/superpowers/).
