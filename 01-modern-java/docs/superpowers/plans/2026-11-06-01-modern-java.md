# 01-modern-java Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Каталог фич Java 9–27 на примерах домена мастерской: модуль `features` (Java 25, пакеты `java09`…`java25`) и `next` (Java 27 + preview, `java26`, `java27`), каждая фича — класс + тест + раздел learning-notes.

**Architecture:** Maven-reactor `01-modern-java` с двумя модулями, parent `../pom.xml`. Пакет на релиз, фича — в версии, где стала финальной. Пакет может использовать типы из пакетов **более ранних** версий (эволюция), но не из более поздних. Тесты — одновременно демонстрации и доказательства.

**Tech Stack:** Java 25/27 (Temurin), JUnit 6, AssertJ, JFR (`jdk.jfr.consumer.RecordingStream`), FFM, `com.sun.net.httpserver` (тесты), Maven Wrapper.

**Spec:** `01-modern-java/docs/superpowers/specs/2026-11-06-01-modern-java-design.md`

**Execution environment:** `mvnw` запускает Dmitry (JDK 27: `$env:JAVA_HOME = "C:\Program Files\Eclipse Adoptium\jdk-27…"`) или CI; агент пишет файлы и коммитит.

## Global Constraints

- Пакеты: `de.ibikus.appa.hephaestus.modernjava.javaNN` (двузначно: `java09`).
- artifactId: reactor `modern-java`, модули `modern-java-features`, `modern-java-next`.
- `features`: `maven.compiler.release=25`, без preview. `next`: `maven.compiler.release=27`, `--enable-preview` для javac и surefire.
- Без фреймворков; Mockito не использовать (агент из parent остаётся, не мешает).
- Фича — в версию, где стала финальной; история превью — в javadoc класса одной строкой.
- Тайминг-пороги — ×5 от ожидаемого; тест с внешней сетью — `@Tag("network")`, исключён по умолчанию.
- Каждая задача: раздел версии(й) в `01-modern-java/docs/learning-notes.md` (что появилось / подводные камни / 2–3 вопроса с ответами) + строки в таблице `docs/architecture.md` + impact-файл `impacts/impact_YYYY_MM_DD_HH.MM.SS.md` в том же коммите.
- Сборка: `.\mvnw.cmd -f 01-modern-java/pom.xml spotless:apply verify` на JDK 27.

## Review Focus

1. **Spotless/palantir не парсит preview-синтаксис** (primitive patterns в `next`) → `spotless:check` падает. Ожидание: сборка зелёная; при сбое — `<skip>` Spotless только для `next` с комментарием (Task 8).
2. **Сборка подпроекта на JDK 25** (по ошибке) → enforcer пропускает (`[25,)`), а `next` падает невнятным `release 27 not supported`. Ожидание: понятное сообщение → enforcer `requireJavaVersion [27,)` в reactor-POM `01` (Task 1).
3. **Флаки тайминга VT в CI** (медленный раннер) → тест падает случайно. Ожидание: порог 2 s при ожидаемых ~0.2 s; тест помечен `@Tag("timing")` (по умолчанию включён) (Task 4).
4. **JFR-событие не успело доставиться** до проверки → ложный «0 событий» в позитивном кейсе pinning. Ожидание: ожидание события с таймаутом через `CountDownLatch`, а не `sleep` (Task 6).
5. **FFM на Windows:** `strlen`/`qsort` не в `defaultLookup()` → `NoSuchElementException`. Ожидание: тест зелёный на Windows и Linux; при отсутствии — `SymbolLookup.libraryLookup("ucrtbase", arena)` на Windows (Task 5).
