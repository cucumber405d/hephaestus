**RU.** Спека 06: три модуля — Inventory (склад с версиями API v1/v2 и устареванием v1, внутренний резерв,
идемпотентный по заказу, с блокировкой строк склада), Ordering (декларативный клиент `@HttpExchange` над
`RestClient`, таймауты 1/2 s, ошибки соседа → свои 409/422/503 + `Retry-After`), Gateway (Spring Cloud Gateway
Server Web MVC, наружу только публичные пути). Заглушки соседей в тестах — JDK `HttpServer`. E2E — Compose из
Jib-образов. CI: verify → e2e → три образа в GHCR. Деплой на платформу за флагом до первой публикации.

**EN.** 06 design and plan: Inventory (versioned API, idempotent locked reservations), Ordering (HTTP interface
client with timeouts and error translation), Spring Cloud Gateway Web MVC; Compose e2e; CI publishing; platform deploy behind a flag.
