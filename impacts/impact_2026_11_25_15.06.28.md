---
name: 15-msys-no-pathconv-scoped
description: MSYS_NO_PATHCONV only for docker compose calls — curl on the host needs /dev/null translated
---

**RU.** Глобальный `MSYS_NO_PATHCONV=1` сломал `curl -o /dev/null` на хосте (Windows-curl получил путь без
перевода): регистрация коннектора считала Connect недоступным, хотя тот отвечал 200. Переменная теперь ставится
только в функции `compose()` скриптов e2e, drills, reconcile.

**EN.** A global `MSYS_NO_PATHCONV=1` broke `curl -o /dev/null` on the host (Windows curl got the path
untranslated), so connector registration saw Connect as unreachable while it answered 200. The variable is now set
only inside the `compose()` function of the e2e, drills and reconcile scripts.
