RU: Logback appender 2.32 тянул `opentelemetry-api-incubator` 1.66, несовместимый с SDK 1.62 из Boot 4.1: `NoClassDefFoundError: ExtendedAttributes` в экспорте логов и — через appender — в потоке отправки outbox (публикации не завершались). Appender понижен до 2.28.1 (целевой SDK 1.62.0), `api-incubator` закреплён на 1.62.0-alpha, `semconv` — на 1.41.1. Агент Delivery (отдельная JVM) остаётся 2.32.0.

EN: OpenTelemetry instrumentation aligned with the SDK version Boot manages.
