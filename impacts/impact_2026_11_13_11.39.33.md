**RU.** Спека `03-containers-ci`: облегчённый Catalog (4 эндпоинта, Postgres + Flyway, эндпоинт Actuator
`runtime` — что видит JVM) собирается четырьмя способами — Buildpacks, Jib (канонический), Dockerfile со слоями
Spring Boot, Dockerfile с jlink-JRE. Один набор образных тестов (профиль `image-it`) для всех: health, сценарий
API, JSON-логи, не root, graceful shutdown; тесты лимитов CPU/памяти/GC — у Buildpacks свои ожидания
(memory calculator). Скрипт сравнения цифрами, Compose со всем стеком, CI: verify → матрица образов → публикация
в GHCR через новый reusable `publish-image.yml` только с `main`. В корневой спеке §5.3 публикация вынесена
из `build-subproject.yml` в отдельный reusable.

**EN.** Approved design for `03-containers-ci`: a slim Catalog built four ways (Buildpacks, Jib as canonical,
layered Dockerfile, jlink Dockerfile), one shared image test suite plus container-limit tests with
Buildpacks-specific expectations, a numeric comparison script, full-stack Compose, and CI that publishes the
Jib image to GHCR via a new reusable `publish-image.yml` after all image tests pass. Root spec §5.3 updated.
