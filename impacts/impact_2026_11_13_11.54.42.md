---

**RU.** Собственный эндпоинт Actuator `runtime`: что видит JVM — число CPU, максимальный heap, лимит памяти
контейнера из `/sys/fs/cgroup/memory.max` (`max`, мусор, нет файла → `null`, без ошибок), имена GC, версия Java,
аргументы JVM. На нём держатся тесты лимитов контейнера.

**EN.** Custom Actuator endpoint `runtime` exposing CPU count, max heap, cgroup v2 memory limit (null when
unknown, never an error), GC names, Java version and JVM arguments; basis for the container-limit tests.
