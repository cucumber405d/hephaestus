name: 06-service-communication — Gateway / Spring Cloud Gateway
description: Spring Cloud Gateway Server Web MVC — маршруты /api/orders и /api/stock из конфигурации, внутренний API не выставлен.
---

**RU.** Gateway на Spring Cloud Gateway Server Web MVC (servlet, virtual threads, без WebFlux): маршруты только
из `application.yaml` — `/api/orders/**` → Ordering, `/api/stock/**` → Inventory (адреса из `ORDERING_URL`,
`INVENTORY_URL`), заголовок ответа `X-Gateway`; всё остальное, в т. ч. внутренний `/api/reservations`, — 404.
IT: настоящий Gateway перед двумя заглушками на JDK `HttpServer` — маршрутизация, тело POST, проброс
`API-Version`, недоступность внутреннего API.

**EN.** Spring Cloud Gateway (Web MVC) with configuration-only routes; internal API not exposed; routing IT
against JDK HttpServer stubs.
