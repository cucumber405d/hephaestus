**RU.** Создан подпроект `01-modern-java`: reactor + модули `features` (release 25) и `next`
(release 27, `--enable-preview`), enforcer требует JDK 27. Примеры Java 9 (неизменяемый каталог материалов
на `Map.of`, private-методы интерфейса в `PriceFormatter`, таймаут поставщика через `completeOnTimeout`)
и Java 10 (`var`, неизменяемый снимок заказа на `List.copyOf`) с тестами и learning-notes.
CI: reusable workflow получил вход `java-version`, `01-modern-java.yml` собирает на JDK 27.
Ограничение: palantir-java-format не работает на JDK 27 — проверка форматирования в `01` отключена,
форматировать под JDK 25.

**EN.** Adds `01-modern-java`: reactor with `features` (release 25) and `next` (release 27, preview),
JDK 27 enforced. Java 9 and 10 examples with tests and learning notes. Reusable CI gains a `java-version`
input; `01-modern-java.yml` builds on JDK 27. palantir-java-format cannot run on JDK 27, so the format
check is skipped in this subproject; formatting is done with JDK 25.
