---
name: 15-idempotent-schema-registration
description: register-schemas.sh survives a second run; connector-init no longer restarts its dependencies
---

**RU.** e2e и учения падали на регистрации коннектора: `compose run connector-init` заново запускал одноразовый
`schema-init`, а повторная регистрация версии 1.1.0 даёт в Apicurio 409. То же ждало k8s — Sync hook выполняется
при каждой синхронизации Argo. Теперь `register-schemas.sh` оставляет уже зарегистрированную версию и заново ставит
правило; `compose run` идёт с `--no-deps`. Самопроверка с фейковым реестром (`scripts/test/register-schemas-fixture.sh`)
запускает скрипт дважды, в CI — в job `checks`.

**EN.** e2e and the drills failed while registering the connector: `compose run connector-init` re-ran the one-shot
`schema-init`, and registering version 1.1.0 again is a 409 in Apicurio (the k8s Sync hook would hit the same on every
sync). register-schemas.sh now keeps an already registered version and sets the rule again; `compose run` uses
`--no-deps`. A fake-registry fixture runs the script twice, in CI's checks job.
