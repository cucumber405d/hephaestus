**RU.** Reactor `service-communication` (Spring Cloud 2025.1.3, общая Jib-конфигурация, модули inventory/ordering/gateway),
CI verify, бейдж. Inventory: `GET /api/stock/{sku}` в двух версиях по заголовку `API-Version` (v1 по умолчанию и
устарел — `Deprecation`, `Sunset`, `Link`; v2 — полная картина); внутренний `POST /api/reservations` — всё или
ничего, идемпотентен по `orderId` (повтор → 200 тот же резерв), строки склада блокируются `FOR UPDATE` в порядке
SKU, проверка повтора — после блокировки. Тесты: домен, сервис на фейках, web slice (версии, коды), IT на
PostgreSQL — гонка за последние единицы и параллельные повторы одного заказа; ArchUnit.

**EN.** Reactor with Spring Cloud BOM and shared Jib config; Inventory with a versioned stock API (v1 deprecated)
and idempotent, row-locked reservations; unit, slice and concurrency tests on PostgreSQL.
