**RU.** `ContainerLimitsImageIT` запускает образ под лимитами `--cpus`/`--memory` и читает `/actuator/runtime`:
1 CPU → 1 процессор и SerialGC, 0.5 CPU → 1, `ActiveProcessorCount=3` → 3, 768 МБ → heap ≈ 75 %, 2 CPU / 2 ГБ → G1.
Для Buildpacks проверяется только видимый лимит памяти, цифры memory calculator пишутся в лог для заметок.
В learning-notes — таблица опытов, server-class machine, 25 % по умолчанию, OOMKill (137) против OOME.

**EN.** Container-limit tests reading `/actuator/runtime` under docker CPU/memory limits (CPU count, 0.5 CPU
rounding, ActiveProcessorCount override, heap ≈ 75 %, Serial vs G1); Buildpacks gets its own expectations.
