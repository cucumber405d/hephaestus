---
name: 15-drills-order-ids
description: Drills write one order id per line; a reconciliation over zero accepted orders fails
---

**RU.** Учения склеивали id заказов в одну строку (`curl` отдаёт ответ без перевода строки, `sed` его не добавляет),
сверка видела 0 заказов: учения 1, 2, 5 проходили впустую, 3, 4 и modulith падали на предусловиях. Теперь каждый
id пишется отдельной строкой, а сверка без единого принятого заказа считается провалом.

**EN.** The drills glued order ids into one line (curl's response has no trailing newline, so sed added none) and
reconciled zero orders: drills 1, 2, 5 passed vacuously, 3, 4 and modulith failed their preconditions. Each id is now
written on its own line, and a reconciliation over zero accepted orders fails.
