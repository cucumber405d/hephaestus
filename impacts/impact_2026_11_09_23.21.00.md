---
name: 02-rest-service — поиск изделий / item search
description: Поиск с фильтрами, сортировкой по белому списку и пагинацией; доказано отсутствие N+1.
---

**RU.** `GET /api/items` фильтрует по категории, диапазону цен (включительно) и подстроке имени без учёта
регистра (включая кириллицу); `%` и `_` в запросе ищутся буквально, а не как шаблоны. Сортировка — только
`name`, `price`, `createdAt` (префикс `-` — по убыванию), с добавочным порядком по `id` для стабильных страниц.
Неверное поле сортировки, размер страницы вне 1–100 или `minPrice > maxPrice` — `400` в формате Problem Details.
Тест через статистику Hibernate доказывает: страница результатов — ровно два SQL-запроса (выборка + count),
N+1 нет. Ошибки валидации параметров сгенерированного интерфейса теперь тоже отдают `400`, а не `500`.

**EN.** Item search with category, inclusive price range and case-insensitive name filters (wildcards escaped),
whitelisted sorting with a stable id tie-break, offset pagination and 400 problems for bad parameters; a Hibernate
statistics test proves a page costs exactly two SQL statements.
