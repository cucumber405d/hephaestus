---
name: 02-rest-service — контракт API / API contract
description: Написан контракт catalog-api.yaml (OpenAPI 3.1), из него генерируются интерфейсы и DTO.
---

**RU.** `catalog-api.yaml` описывает все 10 операций каталога: коды ответов, заголовки `Location`, `ETag`,
`If-Match`, `Idempotency-Key`, схемы ресурсов и Problem Details для ошибок. openapi-generator собирает из него
`CategoriesApi`, `ItemsApi` и 8 DTO — контроллеры будут их реализовывать, расхождение с контрактом
не скомпилируется. Тело PATCH оставлено свободным объектом (нужно различать «ключа нет» и `null`);
`If-Match` объявлен необязательным, чтобы сервис мог ответить `428`, а не `400`. Артефакт валидатора
контракта обновлён на новые координаты `openapi-request-validator-mockmvc`.

**EN.** Hand-written OpenAPI 3.1 contract for all catalog operations; openapi-generator produces the API
interfaces and DTOs controllers must implement. PATCH body stays a free-form map (absent vs null), If-Match
is optional in the contract so the service can answer 428. Validator artifact moved to its new coordinates.
