**RU.** Добавлен `_template/` — эталон, с которого копируются все новые подпроекты, и одновременно живая
проверка корневого `hephaestus-parent`. Внутри один сервис `greeting-service` в гексагональной структуре
(`domain` → `application` → `adapter.in.web`): `GET /api/greetings/{recipient}` → `{"message":"Hello, …!"}`,
невалидный адресат (пустой или > 50 символов) → `400` в формате RFC 9457 Problem Details.
Заложены обязательные для всех подпроектов настройки: virtual threads, graceful shutdown,
liveness/readiness probes, ECS-JSON логи в stdout, конфиг через env (`PORT`).
Тесты: unit (домен, сервис), `@WebMvcTest`, ArchUnit (домен без Spring, зависимости внутрь), `*IT` через HTTP.
В `hephaestus-parent` Mockito подключён как `-javaagent` (с JDK 21 self-attach даёт предупреждение по JEP 451, будущие JDK его запретят) — для всех подпроектов.
Сборка: `.\mvnw.cmd -f _template/pom.xml verify` — 10 unit + 2 IT, зелёная.

**EN.** Adds `_template/`, the reference subproject every new subproject is copied from, and a living check
of the root `hephaestus-parent`. One hexagonal `greeting-service`: `GET /api/greetings/{recipient}` returns a
greeting; an invalid recipient (blank or > 50 chars) returns `400` as RFC 9457 Problem Details.
Bakes in the defaults all subprojects must have: virtual threads, graceful shutdown, health probes,
ECS-JSON logs to stdout, env-based config. Tests: unit, web slice, ArchUnit rules, HTTP-level IT.
The parent now loads Mockito as a `-javaagent` (self-attach warns since JDK 21 per JEP 451 and will be disallowed) for every subproject.
