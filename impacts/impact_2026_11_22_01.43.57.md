---
name: 13 forge.events listener takes the record, not a String
description: Spring Modulith's Kafka JSON support also puts a JSON converter on the listener factory; a String parameter failed with "Cannot deserialize String from Object"
---

**RU.** `ForgeEventsIT` падал: слушатель `forge.events` с параметром `String` получал ошибку конвертации. Опция
Spring Modulith `spring.modulith.events.kafka.enable-json` (по умолчанию включена) ставит JSON-конвертер не только
на отправку, но и на фабрику слушателей. Теперь слушатель сразу принимает запись `ForgeEventMessage`, и конвертер
разбирает её сам. Разбор вручную через `JsonMapper` убран. `CutoverIT` (`@Externalized` в Kafka) уже был зелёным.

**EN.** The forge.events listener failed with a String parameter: Modulith's Kafka JSON support also installs a JSON
message converter on the listener container factory. The listener now takes ForgeEventMessage directly.
