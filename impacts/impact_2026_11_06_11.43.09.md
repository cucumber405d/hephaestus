**RU.** План из 8 задач: каркас + CI на JDK 27 + java09–10; java11–12; java14–18 (records, sealed,
switch, text blocks); java21 (virtual threads, record patterns); java22–23 (FFM, `_`); java24 (Gatherers,
ClassFile API, тест pinning через JFR); java25 (Scoped Values, flexible constructors, compact source);
модуль `next` (HTTP/3, structured concurrency, primitive patterns, lazy constants, PEM). Каждая задача —
тесты, раздел learning-notes, impact. Риски: palantir на preview-синтаксисе, сборка не на той JDK,
флаки тайминга, доставка JFR-событий, FFM-символы на Windows.

**EN.** 8-task plan: scaffold + JDK 27 CI + java09–10; java11–12; java14–18; java21; java22–23 (FFM);
java24 (Gatherers, ClassFile, JFR-based pinning test); java25; `next` module with Java 26/27 previews.
Each task ships tests, learning notes and an impact file. Review focus lists five likely failure modes.
