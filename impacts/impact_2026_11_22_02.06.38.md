**RU.** По финальному ревью 13.
- **C2.** Скрипты были закоммичены без бита исполнения (`100644`). На Linux CI вызов `scripts/e2e.sh` упал бы с
  «Permission denied», Git Bash это скрывает. Теперь `100755`.
- **C3.** `kubectl -n hephaestus-13 apply -k` отказывается применять KafkaTopic, у которых явно указан namespace
  `kafka`. Прикладная часть переехала в `k8s/app`, overlay `local` ставит ей namespace `hephaestus-13`, а
  `deploy-local.sh` применяет топики отдельно. Argo по-прежнему читает `k8s/`: топики плюс `app`.
- **Проверка в CI:** в локальном overlay нет KafkaTopic, и все 9 объектов лежат в `hephaestus-13`.

**EN.** Final review C2/C3: scripts now executable (mode 100755); the namespaced application moved to k8s/app with the
overlay setting hephaestus-13, the topics (namespace kafka) applied separately; a CI render check pins both.
