**RU.** Создан `02-rest-service` с модулем `catalog` на Spring Boot 4.1 (Web MVC, Data JPA, Flyway, Actuator,
MapStruct, springdoc). Flyway-схема: `category` (уникальное имя без учёта регистра), `item` (цена ≥ 0,
FK на категорию, индексы), `idempotency_key`. Hibernate только проверяет схему (`validate`), `open-in-view`
выключен. Интеграционные тесты поднимают настоящий PostgreSQL 17 через Testcontainers и проверяют таблицы
и ограничения. ArchUnit-правила гексагональной архитектуры заложены заранее. Локально — `compose.yaml` +
профиль `local`. CI: `02-rest-service.yml` на JDK 25.

**EN.** Adds `02-rest-service` (Catalog) on Spring Boot 4.1: Flyway schema for categories (case-insensitive
unique names), items (non-negative price, FK) and idempotency keys; Hibernate validates only. Integration tests
run against real PostgreSQL 17 via Testcontainers; hexagonal ArchUnit rules in place; CI on JDK 25.
