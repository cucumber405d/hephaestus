**RU.** Java 11: `PriceListParser` разбирает прайс-лист поставщика (`lines/strip/isBlank`, `Predicate.not`,
`var` в лямбде), `SupplierHttpGateway` запрашивает цену через стандартный `HttpClient` — тест поднимает
встроенный `HttpServer` на случайном порту, без внешних зависимостей; не-200 → `IOException`.
Java 12: `OrderStatistics` считает сумму и среднюю цену за один проход (`Collectors.teeing`), пустой заказ
не делит на ноль; `label` — цепочка `String.transform`. Learning-notes и таблица архитектуры дополнены.

**EN.** Java 11: price-list parsing with the new String API and a supplier gateway on the standard
`HttpClient`, tested against an in-process `HttpServer`. Java 12: total and average in one pass via
`Collectors.teeing` (empty order safe) and `String.transform`. Notes and architecture table updated.
