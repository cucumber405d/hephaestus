- PDB, для которого контроллер ещё не посчитал статус (`<none>`), раньше проходил preflight `drain`. Теперь
  проходит только положительное число разрешённых выселений.
- Если список PDB не читается, прогон останавливается с понятным сообщением, а не молча.
- При выборе узла для drain не учитываются завершённые поды (`Succeeded`/`Failed`), например Job `certgen` у
  Envoy Gateway.

Самотест: новый случай для `<none>`.
