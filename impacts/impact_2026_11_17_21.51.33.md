description: Весь стек в Compose из Jib-образов, e2e через Gateway (версии, заказы, ошибки, сбой Inventory), CI verify → e2e → публикация трёх образов.
---

**RU.** `compose.yaml`: две PostgreSQL, Inventory, Ordering, Gateway (наружу только Gateway на 8080). `scripts/e2e.sh`
собирает Jib-образы и проверяет через Gateway: v1 (только `available`, `Deprecation`, `X-Gateway`), v2, v3 → 400,
заказ 201 и чтение по `Location`, остаток 10 → 8, нехватка 409 с SKU, неизвестный SKU 422, внутренний
`/api/reservations` → 404, остановленный Inventory → 503 + `Retry-After` быстрее 5 s. Сервисы строят `Location` из
`X-Forwarded-*` (`forward-headers-strategy: framework`), Gateway доверяет им только из локальных/частных сетей.
CI: verify → e2e → публикация трёх образов в GHCR (матрица reusable-workflow, только `main`).

**EN.** Compose stack from the Jib images, gateway-only e2e (versions, orders, business errors, internal API hidden,
Inventory outage → fast 503), forwarded headers for public Location URLs, CI verify → e2e → publish three images.
