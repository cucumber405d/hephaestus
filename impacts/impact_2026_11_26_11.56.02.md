**RU.** Задача 4: `EventCodec` — событие ↔ строка журнала (тип = имя record, payload = JSON). При чтении цепочка
upcaster'ов поднимает старую версию схемы до текущей (`WorkOrderStarted` v1 → v2: `smith = "unknown"`); неизвестный
тип или версия новее известной — `UnknownEvent`, событие никогда не пропускается молча.

**EN.** Task 4: `EventCodec` maps events to journal rows and back; reading runs upcasters up to the current schema
version (`WorkOrderStarted` v1 → v2 with smith "unknown"); an unknown type or a newer version is `UnknownEvent`,
never silently skipped.
