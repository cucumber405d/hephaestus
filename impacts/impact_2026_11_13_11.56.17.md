description: Jib-образ hephaestus/catalog:jib, профиль image-it с CatalogImageIT, сервис catalog в compose (профиль app).
---

**RU.** Jib собирает канонический образ на `eclipse-temurin:25-jre`: не root (`1000:1000`), порт 8080,
`JAVA_TOOL_OPTIONS` с `MaxRAMPercentage=75`, OCI-метки. Профиль `image-it` собирает образ (или берёт готовый из
`-Dcatalog.image`) и гоняет `CatalogImageIT`: API, JSON-логи, не root, SIGTERM → graceful shutdown (код 0/143),
`PORT`, падение без БД. В `compose.yaml` — сервис `catalog` в профиле `app`, лимиты 768m / 1 CPU.

**EN.** Jib image (non-root, port 8080, MaxRAMPercentage=75, OCI labels); `image-it` profile running
`CatalogImageIT` against any image (API, JSON logs, non-root, graceful SIGTERM, PORT, fails without DB);
compose `app` profile with the catalog service.
