**RU.** Спека 05: kind-кластер `hephaestus`, Argo CD ставится Helm'ом один раз и дальше управляет всем, включая
себя. Корневое Application — Helm-чарт `platform/apps` с шаблоном на компонент и профилями `minimal`/`full`;
ревизия Git — параметр, поэтому ветка PR проверяется целиком. Компоненты: Envoy Gateway (Gateway API, вход
через `*.localtest.me`), CloudNativePG, Strimzi Kafka (KRaft, v1 API), Keycloak Operator, Redis, grafana/otel-lgtm.
Catalog из 03 на CNPG с порядком через sync waves и хук миграции. Smoke + CI на kind (`minimal`).

**EN.** 05 design and plan: GitOps platform on kind managed by Argo CD (App-of-Apps Helm chart, minimal/full
profiles, revision as a parameter) with Envoy Gateway, CloudNativePG, Strimzi, Keycloak, Redis, otel-lgtm and a
Catalog demo ordered by sync waves; smoke test and CI.
