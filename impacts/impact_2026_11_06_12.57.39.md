**RU.** Модуль `next` (release 27 + `--enable-preview`). Java 26: `Http3Probe` — запрос с HTTP/3 (тест с
выходом в интернет, по умолчанию выключен). Java 27 (превью): `SupplierAggregator` параллельно спрашивает
цену, наличие и срок через `StructuredTaskScope` — тест доказывает, что падение одной подзадачи прерывает
остальные и всё завершается быстрее секунды; `StatusCodes` — primitive patterns в switch по `int`;
`TariffTable` — ленивая однократная загрузка через `LazyConstant`; `KeyPem` — PEM без сторонних библиотек.
Найден дрейф API: в JDK 27 `join()` бросает checked `ExecutionException` (в 25 — `FailedException`).
RED сделан через заглушки (5 падений на assertions).

**EN.** `next` module on JDK 27 with preview: HTTP/3 probe (network-tagged test), structured concurrency that
cancels siblings on the first failure (test-proven), primitive patterns, lazy constants and PEM encoding.
Caught a preview API change: `join()` now throws checked `ExecutionException`. RED via stubs (5 failures).
