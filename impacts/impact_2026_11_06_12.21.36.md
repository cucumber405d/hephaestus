**RU.** Добавлены типы, на которые опираются следующие версии: `Money` (record с валидацией, нормализацией
scale до центов и запретом сложения разных валют), `OrderLine` (итог строки, `mapMulti`, `instanceof`-паттерны),
`sealed interface PaymentResult` (Approved / Declined / Pending) с генератором id транзакции на
`RandomGenerator` + `HexFormat`. Java 14: переходы статусов заказа через switch expression, проверка helpful NPE.
Java 15: JSON-шаблон заказа на text block. Java 18: тест, что кодировка по умолчанию — UTF-8.

**EN.** Adds the domain types later versions build on: `Money` (validated record, cents scale, no cross-currency
addition), `OrderLine` (`mapMulti`, `instanceof` patterns) and the sealed `PaymentResult` hierarchy with a hex
transaction id. Also switch expressions for order status, a text-block JSON template and a UTF-8 default test.
