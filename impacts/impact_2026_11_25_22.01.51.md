---
name: publish-reactor-deps
description: publish-image installs the reactor modules a service depends on before jib:build (15's contracts jar)
---

**RU.** Публикация образов 15 на main упала: `publish-image.yml` собирал сервис через `-pl <module>` без зависимостей
из того же реактора, и `cdc-debezium-contracts:1.1.0` искался в Maven Central. Теперь перед `jib:build` идёт
`-pl <module> -am install -DskipTests` (jib на зависимых модулях не запускается). Матрица публикации 15 —
`fail-fast: false`, чтобы одно падение не отменяло остальные образы.

**EN.** Publishing 15's images on main failed: publish-image.yml built the service with `-pl <module>` and looked for
`cdc-debezium-contracts:1.1.0` in Maven Central. It now runs `-pl <module> -am install -DskipTests` before
`jib:build` (no jib on the upstream modules). 15's publish matrix is `fail-fast: false`, so one failure no longer
cancels the other images.
