RU: `07-security/k8s`: переменные OAuth2 (публичный issuer `http://keycloak.localtest.me`, внутренние ключи/токены
`keycloak-service.keycloak:8080`), Secret с клиентскими секретами (локальные значения), `KeycloakRealmImport` realm
hephaestus в namespace keycloak, NetworkPolicy default deny (Envoy → gateway → ordering → inventory, БД — только своим
сервисам и оператору CNPG, пробы kubelet), HTTPRoute `secure-shop.localtest.me`. Gateway — одна реплика: сессия в памяти пода.
Платформа: Application `security` за флагом `components.security` (выключен до первой публикации образов),
у Keycloak CR включён `backchannelDynamic`. Конфигурации безопасности не создаются в Job миграции (без веб-сервера).

EN: Cluster manifests for 07 (OAuth2 env, secrets, realm import, default-deny NetworkPolicies, own hostname) and a
platform Application behind the `security` flag; Keycloak allows backchannel calls via its internal Service.
