**RU.** Утверждена структура `01-modern-java`: два модуля — `features` (Java 25, все финальные фичи
9–25, пакет на релиз `javaNN`) и `next` (Java 27 + `--enable-preview`: HTTP/3, structured concurrency,
primitive patterns, lazy constants, PEM). Фича кладётся в версию, где стала финальной. Каждая фича —
пример из домена мастерской + тест; ключевые утверждения (масштабирование virtual threads, отсутствие
pinning на `synchronized`, безопасность Scoped Values, отмена соседей в structured concurrency)
доказываются тестами, в том числе через JFR. Подпроект собирается на JDK 27; CI получает вход `java-version`.

**EN.** Design for `01-modern-java`: module `features` (Java 25, all final features 9–25, one package per
release) and module `next` (Java 27 with preview: HTTP/3, structured concurrency, primitive patterns, lazy
constants, PEM). Features live in the release where they became final. Each feature has a domain example and
a test; key claims (virtual-thread scaling, no pinning on `synchronized`, scoped values, structured
cancellation) are proven by tests, partly via JFR. Builds on JDK 27; CI gains a `java-version` input.
