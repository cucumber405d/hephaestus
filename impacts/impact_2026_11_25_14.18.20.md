---
name: 15-msys-no-pathconv
description: e2e, drills and reconcile no longer let Git Bash rewrite container paths
---

**RU.** Проверка «одна запись на заказ» читала не топик, а ошибку Docker: Git Bash превращал
`/opt/kafka/bin/kafka-console-consumer.sh` в `C:/App/Git/opt/...`. `e2e.sh`, `drills.sh` и `reconcile.sh` теперь
ставят `MSYS_NO_PATHCONV=1` (как скрипты 14), а e2e требует в прочитанном хотя бы один ключ-UUID.

**EN.** The one-record-per-order check read a Docker error instead of the topic: Git Bash rewrote
`/opt/kafka/bin/kafka-console-consumer.sh` into `C:/App/Git/opt/...`. e2e.sh, drills.sh and reconcile.sh now set
`MSYS_NO_PATHCONV=1` (like the scripts of 14), and e2e requires at least one UUID key in what it read.
