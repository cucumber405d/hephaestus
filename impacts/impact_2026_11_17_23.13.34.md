name: 07 Gateway as BFF
description: oauth2Login with PKCE, tokens in the session, TokenRelay to backends, CSRF cookie/header, 401 for /api without session.

RU: Gateway стал Backend for Frontend. Браузер держит только HttpOnly-cookie сессии; токены — в серверной сессии.
- Вход: Authorization Code + PKCE (S256), конфиденциальный клиент `shop-gateway`, явные endpoint'ы без discovery,
  `iss` ID-токена проверяется отдельно (`JwtIssuerValidator`).
- Маршруты `/api/orders/**`, `/api/stock/**`: `TokenRelay=` (access token пользователя, обновление по refresh token),
  cookie к бэкендам не уходят.
- CSRF: cookie `XSRF-TOKEN` + заголовок `X-XSRF-TOKEN` (`csrf.spa()`); `/api/**` без сессии → 401, страницы → редирект на вход.
- `/me` — кто вошёл; `POST /logout` — локальный выход.
Тест `GatewayBffIT` проходит весь вход сценарием против заглушки Keycloak (подписанный ID-токен, проверка code_verifier).

EN: The gateway is now a BFF: PKCE login, tokens kept server-side, TokenRelay, SPA-style CSRF, 401 for anonymous API calls.
The IT scripts the full login against a stub Keycloak.
