**RU.** Java 22: FFM API — `NativeStrings` вызывает C `strlen`, `NativeSort` сортирует массив через C `qsort`
с компаратором на Java (upcall) — этот же класс нужен для теста pinning в Java 24; `OffHeapBuffer` пишет и
читает `long` вне кучи с детерминированным освобождением через `Arena`. Unnamed variables `_` в цикле,
`catch` и `switch`. Java 23: enum с Markdown doc comments `///`. В surefire `features` добавлен
`--enable-native-access=ALL-UNNAMED` (иначе предупреждение с JDK 24).

**EN.** Java 22 FFM: `strlen` and `qsort` (with a Java comparator upcall) from the C runtime without JNI,
off-heap memory with arena-scoped release; unnamed `_` variables. Java 23: Markdown doc comments.
Surefire grants native access to avoid the JDK 24+ warning.
