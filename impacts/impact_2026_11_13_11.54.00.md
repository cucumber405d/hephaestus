**RU.** `GET /api/categories`, `GET /api/items?category=`, `GET /api/items/{id}`, `POST /api/items` (`201` +
`Location`). Суммы — строки. Ошибки: `invalid-request` (в т. ч. кривой UUID и JSON), `not-found`,
`unknown-category`, `internal-error` без деталей. Тесты web-slice на фейках, сценарий на PostgreSQL, ArchUnit-правила
из 02; `requests.http` для IntelliJ.

**EN.** Four Catalog endpoints, string amounts, Problem Details for 400/404/422/500 (no leak), web-slice tests,
scenario IT on PostgreSQL, ArchUnit rules from 02, `requests.http`.
