**RU.** `PriceGatherers`: свой gatherer `distinctBy` и скользящее среднее цен на `windowSliding`;
тест показывает встроенные `windowFixed`, `fold`, `scan`, `mapConcurrent`. `ClassInspector` читает имена
методов из `.class` через Class-File API вместо ASM. `PinningTest` через JFR-событие `jdk.VirtualThreadPinned`
доказывает суть JEP 491: блокировка в `synchronized` больше не пинит carrier, а блокировка внутри нативного
кадра (upcall из C `qsort`) по-прежнему пинит. События ждём через latch — без флаки на асинхронной доставке JFR.

**EN.** Custom `distinctBy` gatherer and moving average; Class-File API instead of ASM; a JFR-based test that
proves JEP 491: blocking inside `synchronized` no longer pins a virtual thread, blocking in a native frame
(a `qsort` upcall) still does.
