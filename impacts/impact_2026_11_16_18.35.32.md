**RU.** `platform/kind/cluster.yaml`: control-plane + 2 worker, NodePort 30080 Gateway → `localhost:80`.
`platform/bootstrap.sh [minimal|full] [ревизия]`: создаёт кластер (если нет), ставит Argo CD Helm'ом (версия из
values App-of-Apps), применяет корневое Application `platform`. Argo CD управляет и собой (multi-source: чарт +
`platform/argocd/values.yaml` из Git); в values — health для Application (чтобы волны App-of-Apps ждали
готовности) и OCI-репозитории Helm. `platform/apps` — Helm-чарт: Application на компонент, волны
(операторы → Gateway → приложения), automated sync с prune/selfHeal, ServerSideApply, retry; профили minimal/full.

**EN.** Platform cluster config, bootstrap script (Argo CD via Helm once, root App-of-Apps for a profile and Git
revision), self-managed Argo CD with Application health and OCI repos, App-of-Apps Helm chart with waves and profiles.
