---

**RU.** `up.sh` создаёт kind-кластер `hephaestus-04` и деплоит. `deploy.sh` применяет overlay по меткам
`component`: namespace/config/database → пересоздаёт Job миграции и ждёт успеха (при провале печатает лог) → API
и ждёт rollout. `smoke.sh`: Job успешен, у API Flyway выключен, миграции в `flyway_schema_history`, 3 категории,
POST 201 → GET 200, `/actuator/runtime` — 1 CPU и лимит 768Mi, `rollout restart` под нагрузкой из пода в
кластере — 0 неуспешных запросов. `down.sh` удаляет кластер.

**EN.** Ordered deploy (DB → migration Job → API), smoke test (migration, API round trip, JVM limits in the pod,
zero failed requests during a rollout restart under in-cluster load), up/down helpers for kind.
