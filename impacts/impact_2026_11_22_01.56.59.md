**RU.** Задача 8 подпроекта 13.
- **CI.** `compose.yaml` поднимает монолит, Forge-сервис, заглушку поставщика, Kafka и две отдельные базы.
  `scripts/e2e.sh` запускает генератор и «кузнеца-бота» и ведёт монолит по шагам `before → cutover → drain →
  decommission`. Затем проверяет 410 у API кузнеца в монолите и сверку. Обе стороны должны были обслужить заказы.
- **kind.** Kustomize: две базы CNPG, топики Strimzi, три Deployment-а. Статический `HTTPRoute` — фасад
  «удушения»: `WO-…` по регулярке пути идут в монолит, остальной API кузнеца — в сервис, всё прочее — в монолит.
  `deploy-local.sh` собирает образы, загружает их в kind и применяет overlay `local`. `live.sh` повторяет e2e через
  Envoy Gateway.
- **Argo.** Компонент `modularMonolith` в `platform/` выключен, пока CI не опубликует образы.
- `legacy` и `traffic` не собирают образы (`jib.skip`).

**EN.** Compose stack and e2e.sh (cutover steps under continuous orders and a smith bot, 410 after decommission,
reconciliation, both sides must have served work orders); Kustomize for kind with the static Strangler HTTPRoute
(WO- path regex to the monolith), deploy-local.sh with local images, live.sh through the Envoy Gateway; Argo
component off until the images are published; no images for legacy and traffic.
