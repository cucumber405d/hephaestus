**RU.** Утверждён дизайн `02-rest-service`: сервис Catalog с агрегатами `Item` и `Category`. API пишется
контрактом `catalog-api.yaml` (OpenAPI 3.1), код генерирует openapi-generator, ответы дополнительно
проверяет контрактный тест. Production-grade REST: поиск с фильтрами/сортировкой/пагинацией, ETag + `If-Match`
(`412`/`428`), JSON Merge Patch, идемпотентный POST по `Idempotency-Key`, Problem Details, версионирование
API Spring 7. Строгая гексагональная архитектура (домен без JPA, MapStruct), Flyway, Testcontainers;
тест доказывает, что поиск — ровно 2 SQL-запроса.

**EN.** Design for `02-rest-service`: a Catalog service (Item, Category) with a hand-written OpenAPI 3.1
contract, generated interfaces plus a contract test, production-grade REST (ETag/If-Match, merge patch,
idempotency keys, Problem Details, API versioning), strict hexagonal architecture with MapStruct, Flyway and
Testcontainers; a test proves the item search runs exactly two SQL statements.
