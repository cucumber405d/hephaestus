**RU.** Задача 3: наряд (`WorkOrder`) и материал (`Material`) — чистые функции `decide` (команда + состояние →
события) и `evolve` (состояние + событие → состояние) на sealed-интерфейсах и records Java 25. Id наряда —
`FW-<orderId>` (он же id потока), поток материала — `material-<code>`. Повторный запрос ничего не порождает;
неподходящая команда — `WorkOrderRefused`; взять больше остатка — `InsufficientStock`.

**EN.** Task 3: work order and material as pure `decide`/`evolve` functions over sealed interfaces and records;
work order id `FW-<orderId>` (also the stream id), material stream `material-<code>`; a repeated request yields
nothing, an unfitting command is `WorkOrderRefused`, taking more than on hand is `InsufficientStock`.
